📖 درس ۱: مقدمه پایتون

🐍 پایتون چیست؟

یک زبان برنامه‌نویسی سطح بالا و شی‌گرا که در سال ۱۹۹۱ ساخته شد.

مزایا:

  • سادگی و خوانایی
  • کتابخانه‌های فراوان
  • استفاده در هوش مصنوعی

اولین کد:

print("سلام دنیا!")

📖 درس ۲: متغیرها

📦 متغیر چیست؟

ظرفی برای ذخیره داده.

name = "علی"
age = 25
height = 1.75

انواع داده:

  • int: عدد صحیح
  • float: عدد اعشاری
  • str: متن
  • bool: درست/غلط
print(type(5))

📖 درس ۳: رشته‌ها

📝 رشته چیست؟

text = "سلام دنیا"
print(len(text))
print(text[0])
print(text.upper())

f-string:

name = "علی"
print(f"سلام {name}")

📖 درس ۴: شرط‌ها

🤔 if/else:

age = 18
if age >= 18:
    print("بزرگسال")
else:
    print("کودک")

elif:

score = 85
if score >= 90:
    print("عالی")
elif score >= 75:
    print("خوب")
else:
    print("تلاش کن")

📖 درس ۵: حلقه‌ها

🔄 حلقه for:

for i in range(5):
    print(i)

🔄 حلقه while:

i = 1
while i <= 5:
    print(i)
    i += 1

break:

for i in range(10):
    if i == 5:
        break
