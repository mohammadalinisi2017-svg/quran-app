📖 درس ۱: مقدمه پایتون

🐍 پایتون چیست؟

یک زبان برنامه‌نویسی سطح بالا، تفسیری و شی‌گرا که توسط گیدو ون روسوم در سال ۱۹۹۱ ساخته شد.

مزایا:

  • سادگی و خوانایی بالا
  • کتابخانه‌های فراوان
  • استفاده در هوش مصنوعی
  • رایگان و متن‌باز

اولین کد:

print("سلام دنیا!")

📖 درس ۲: نصب پایتون

💻 نصب روی کامپیوتر:

  • برو به python.org
  • آخرین نسخه را دانلود کن
  • تیک Add to PATH را بزن
  • نصب کن

📱 نصب روی موبایل:

  • اندروید: Pydroid 3
  • آیفون: Pythonista

✏️ تست:

print("سلام!")
print(2 + 3)

📖 درس ۳: متغیرها

📦 متغیر چیست؟

ظرفی برای ذخیره داده در حافظه.

name = "علی"
age = 25
height = 1.75
is_student = True

انواع داده:

  • int: عدد صحیح (25, -10)
  • float: عدد اعشاری (1.75)
  • str: متن ("علی")
  • bool: درست/غلط (True/False)

بررسی نوع:

x = 5
print(type(x))   # int

📖 درس ۴: رشته‌ها

📝 رشته چیست؟

name = "علی"
message = 'سلام'

عملیات روی رشته:

text = "سلام دنیا"
print(len(text))         # طول
print(text[0])           # اولین حرف
print(text[-1])          # آخرین حرف
print(text.upper())      # حروف بزرگ
print(text.replace("دنیا","جهان"))

f-string:

name = "علی"
age = 25
print(f"اسم من {name} است")

📖 درس ۵: عملگرها

➗ عملگرهای ریاضی:

a = 10
b = 3
print(a + b)   # جمع: 13
print(a - b)   # تفریق: 7
print(a * b)   # ضرب: 30
print(a / b)   # تقسیم: 3.33
print(a // b)  # تقسیم صحیح: 3
print(a % b)   # باقیمانده: 1
print(a ** b)  # توان: 1000

مقایسه:

  • == مساوی
  • != نامساوی
  • > بزرگتر
  • < کوچکتر
  • >= بزرگتر یا مساوی
  • <= کوچکتر یا مساوی

📖 درس ۶: ورودی و خروجی

📤 print:

print("سلام")
print(10, 20, 30)

📥 input:

name = input("اسمت چیه؟ ")
print("سلام " + name)

⚠️ نکته:

خروجی input همیشه رشته است.

age = int(input("سن: "))
print(age + 1)

📖 درس ۷: شرط‌ها (if/else)

🤔 شرط:

age = 18
if age >= 18:
    print("بزرگسال")
else:
    print("کودک")

elif:

score = 85
if score >= 90:
    print("عالی")
elif score >= 75:
    print("خوب")
elif score >= 50:
    print("قابل قبول")
else:
    print("تلاش کن")

شرط کوتاه:

x = 10
result = "مثبت" if x > 0 else "منفی"

📖 درس ۸: حلقه‌ها (for/while)

🔄 حلقه for:

for i in range(5):
    print(i)
# 0, 1, 2, 3, 4

range با شروع:

for i in range(2, 8):
    print(i)
# 2 تا 7

🔄 حلقه while:

i = 1
while i <= 5:
    print(i)
    i += 1

کنترل حلقه:

for i in range(10):
    if i == 5:
        break
    print(i)

📖 درس ۹: لیست‌ها (Lists)

📋 لیست:

numbers = [1, 2, 3, 4, 5]
names = ["علی", "رضا", "سارا"]

دسترسی:

fruits = ["سیب", "موز", "پرتقال"]
print(fruits[0])     # سیب
print(fruits[-1])    # پرتقال

اضافه کردن:

fruits.append("انگور")
fruits.insert(1, "گلابی")

حذف کردن:

fruits.remove("موز")
fruits.pop()

متدهای مهم:

nums = [3, 1, 4, 1, 5]
print(len(nums))     # تعداد
nums.sort()          # مرتب‌سازی
print(sum(nums))     # مجموع
print(max(nums))     # بیشترین

📖 درس ۱۰: تاپل‌ها (Tuples)

📦 تاپل:

مثل لیست ولی غیرقابل تغییر.

point = (3, 5)
colors = ("قرمز", "سبز", "آبی")

دسترسی:

print(point[0])    # 3
print(colors[-1])  # آبی

تفکیک:

x, y = (3, 5)
print(x)   # 3
print(y)   # 5

چرا تاپل؟

  • سریع‌تر از لیست
  • امن‌تر (تغییر نمی‌کند)

📖 درس ۱۱: دیکشنری‌ها

📖 دیکشنری:

person = {
    "name": "علی",
    "age": 25,
    "city": "تهران"
}

دسترسی:

print(person["name"])       # علی
print(person.get("age"))    # 25

اضافه/تغییر:

person["age"] = 26
person["job"] = "برنامه‌نویس"

حذف:

del person["city"]

پیمایش:

for key, value in person.items():
    print(key, ":", value)

📖 درس ۱۲: مجموعه‌ها (Sets)

🎯 مجموعه:

مجموعه‌ای بدون تکرار و بدون ترتیب.

numbers = {1, 2, 3, 4, 5}
nums = {1, 2, 2, 3, 3}
print(nums)   # {1, 2, 3}

اضافه کردن:

numbers.add(6)

عملیات مجموعه:

a = {1, 2, 3}
b = {3, 4, 5}
print(a | b)   # اجتماع
print(a & b)   # اشتراک
print(a - b)   # تفاضل

📖 درس ۱۳: توابع (Functions)

🎯 تابع چیست؟

def greet():
    print("سلام!")

greet()

با پارامتر:

def greet(name):
    print("سلام " + name)

greet("علی")

با return:

def add(a, b):
    return a + b

print(add(5, 3))   # 8

مقدار پیش‌فرض:

def greet(name="دوست"):
    print("سلام " + name)

📖 درس ۱۴: توابع پیشرفته

⚡ Lambda:

square = lambda x: x * x
print(square(5))   # 25

با map:

nums = [1, 2, 3, 4]
squares = list(map(lambda x: x**2, nums))
print(squares)   # [1, 4, 9, 16]

با filter:

evens = list(filter(lambda x: x % 2 == 0, nums))
print(evens)   # [2, 4]

📖 درس ۱۵: کلاس‌ها و شی‌گرایی

🏗️ کلاس:

class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
    
    def introduce(self):
        return "من " + self.name + " هستم"

p1 = Person("علی", 25)
print(p1.introduce())

مفاهیم کلیدی:

  • class: تعریف کلاس
  • __init__: سازنده
  • self: اشاره به شیء

📖 درس ۱۶: ارث‌بری

🧬 ارث‌بری:

class Animal:
    def __init__(self, name):
        self.name = name
    
    def sound(self):
        return "صدا"

class Dog(Animal):
    def sound(self):
        return "واق واق!"

dog = Dog("رکس")
print(dog.name)      # رکس
print(dog.sound())   # واق واق!

استفاده از super():

class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)
        self.breed = breed

📖 درس ۱۷: فایل‌ها

📁 نوشتن در فایل:

with open("test.txt", "w") as f:
    f.write("سلام دنیا!")

📖 خواندن از فایل:

with open("test.txt", "r") as f:
    content = f.read()
    print(content)

حالت‌های باز کردن:

  • "r": خواندن
  • "w": نوشتن (پاک می‌کند)
  • "a": اضافه کردن

📖 درس ۱۸: مدیریت خطا

⚠️ try/except:

try:

    print("تقسیم بر صفر!")

انواع خطا:

  • ZeroDivisionError
  • ValueError
  • TypeError
  • KeyError
  • IndexError

چند خطا:

try:

📖 درس ۲۰: پروژه‌های عملی

🎯 پروژه ۱: ماشین حساب:

a = float(input("عدد اول: "))
op = input("عملگر: ")
b = float(input("عدد دوم: "))
if op == "+":
    print(a + b)
elif op == "-":
    print(a - b)
elif op == "*":
    print(a * b)
elif op == "/":
    print(a / b)

🎮 پروژه ۲: بازی حدس عدد:

import random
number = random.randint(1, 100)
while True:
    guess = int(input("حدس: "))
    if guess < number:
        print("بالاتر!")
    elif guess > number:
        print("پایین‌تر!")
    else:
        print("درست!")
        break
