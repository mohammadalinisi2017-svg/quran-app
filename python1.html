🐍 پایتون برای همه

🎯 سلام!

این آموزش خیلی ساده نوشته شده. حتی اگه هیچ چیزی از برنامه‌نویسی نمی‌دونی، می‌تونی یاد بگیری!

فقط کافیه اسکرول کنی و بخونی.

📖 درس ۱: پایتون چیه؟

پایتون یه زبون برنامه‌نویسی هست. یعنی یه زبون که با کامپیوتر حرف می‌زنی.

مثل اینکه با یه دوست خارجی حرف می‌زنی، ولی این بار با کامپیوتر.

💡 چرا پایتون؟
چون ساده‌ست و خیلی راحت یاد می‌گیری!

اولین برنامه:

print("سلام")

این کد، کلمه «سلام» رو چاپ می‌کنه.

بذار یه چیز دیگه هم چاپ کنیم:

print("اسم من علی است")

همین! به همین سادگی!

📖 درس ۲: چاپ کردن

کلمه print یعنی «چاپ کن». هرچی توی پرانتز بذاری، چاپ می‌شه.

مثال‌ها:

print("سلام دنیا")
print("من پایتون یاد می‌گیرم")
print(5)
print(10 + 20)

خروجی آخری می‌شه: 30

💡 نکته:
اگه متن باشه، باید بین " بذاری. مثل: "سلام"
اگه عدد باشه، نیازی به " نیست. مثل: 5

📖 درس ۳: ذخیره کردن (متغیر)

تصور کن یه جعبه داری که هرچی می‌خوای توش بذاری. به این جعبه می‌گن متغیر.

مثال:

name = "علی"
print(name)

اینجا «علی» رو توی جعبه‌ای به اسم name گذاشتیم.

بعدش با print نشونش دادیم.

چند تا جعبه:

name = "علی"
age = 25
print(name)
print(age)
💡 یعنی چی؟
name = اسم
age = سن
اسم جعبه رو خودت انتخاب می‌کنی.

📖 درس ۴: حساب کردن

پایتون مثل ماشین حساب کار می‌کنه!

جمع و تفریق:

print(5 + 3)    # می‌شه 8
print(10 - 4)   # می‌شه 6

ضرب و تقسیم:

print(4 * 3)    # می‌شه 12
print(10 / 2)   # می‌شه 5

با متغیر:

a = 10
b = 5
print(a + b)    # می‌شه 15
print(a - b)    # می‌شه 5
💡 علامت‌ها:
➕ + جمع
➖ - تفریق
✖️ * ضرب
➗ / تقسیم

📖 درس ۵: نظر دادن (کامنت)

گاهی می‌خوای یه توضیح بنویسی، ولی نمی‌خوای پایتون اجراش کنه.

با علامت # این کار رو می‌کنی.

# این یه توضیحه
print("سلام")   # این چاپ می‌شه
💡 فایده‌ش چیه؟
بعداً که کدت رو می‌بینی، می‌فهمی هر قسمت چیکار می‌کنه!

📖 درس ۶: گرفتن ورودی

می‌خوای از کاربر سوال بپرسی؟ از input استفاده کن!

name = input("اسمت چیه؟ ")
print("سلام " + name)

وقتی اجرا کنی:

  • می‌پرسه: اسمت چیه؟
  • کاربر جواب می‌ده: مثلاً علی
  • بعد چاپ می‌شه: سلام علی
💡 نکته:
خروجی input همیشه متن هست.

📖 درس ۷: تصمیم گرفتن (if)

گاهی می‌خوای برنامه تصمیم بگیره. مثلاً:

  • اگه سن بالای ۱۸ بود → بزرگسال
  • اگه نبود → کودک
age = 20
if age >= 18:
    print("بزرگسال")
else:
    print("کودک")
💡 یعنی چی؟
if = اگه
else = وگرنه
⚠️ نکته مهم: خط زیر if باید ۴ تا فاصله داشته باشه!

مثال دیگه:

score = 85
if score >= 90:
    print("عالی")
else:
    print("خوب")

📖 درس ۸: تکرار کردن (حلقه)

می‌خوای یه کار رو چند بار تکرار کنی؟ از for استفاده کن!

مثال:

for i in range(5):
    print(i)

خروجی:

0
1
2
3
4
💡 یعنی چی؟
range(5) یعنی از 0 تا 4 (۵ تا عدد)

مثال دیگه:

for i in range(3):
    print("سلام")

خروجی: سه بار «سلام» چاپ می‌شه.

📖 درس ۹: لیست (چند تا چیز توی یه جعبه)

فرض کن می‌خوای چند تا اسم ذخیره کنی. به جای چند تا متغیر، از لیست استفاده کن!

names = ["علی", "رضا", "سارا"]
print(names)

خروجی: ['علی', 'رضا', 'سارا']

دسترسی به هر کدوم:

names = ["علی", "رضا", "سارا"]
print(names[0])   # علی
print(names[1])   # رضا
print(names[2])   # سارا
💡 نکته:
شماره‌گذاری از 0 شروع می‌شه، نه 1!

اضافه کردن:

names = ["علی", "رضا"]
names.append("سارا")
print(names)   # ['علی', 'رضا', 'سارا']

📖 درس ۱۰: تمرین! 🎯

حالا وقت تمرینه! اینا رو خودت امتحان کن:

تمرین ۱: چاپ اسم خودت

print("اسم من ___ است")

جای خالی رو با اسم خودت پر کن.

تمرین ۲: جمع دو عدد

a = 10
b = 20
print(a + b)

خروجی چیه؟

تمرین ۳: سوال از کاربر

name = input("اسمت چیه؟ ")
print("سلام " + name)

تمرین ۴: تصمیم

age = 15
if age >= 18:
    print("بزرگسال")
else:
    print("کودک")

خروجی چیه؟
